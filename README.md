# 🌸 Portafolio de Moda - Patricia

Portafolio profesional de Creative Director y Stylist, construido con **Astro**, **Starwind UI** y **Tailwind CSS**.

## ✨ Características

- 🚀 **Astro** - Framework moderno con SSG (Static Site Generation)
- 🎨 **Starwind UI** - Componentes elegantes preconstructuidos para Astro
- 🎨 **Tailwind CSS** - Diseño responsive y moderno
- 📱 **Responsive** - Optimizado para todos los dispositivos
- 🎯 **SEO Optimizado** - Meta tags y estructura semántica
- ⚡ **Rendimiento** - Carga ultrarrápida sin JavaScript innecesario
- 🌈 **Paleta minimalista de moda** - Colores sofisticados y elegantes
